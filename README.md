# WorkFocusManager

WPF 기반 집중 타이머 앱입니다. 집중 시간 동안 방해되는 프로세스를 감지하고, 블랙리스트에 등록된 프로세스를 유예 시간 후 종료해 집중 흐름을 유지하도록 돕습니다.

## 주요 기능

- 집중 타이머 시작, 일시정지, 초기화
- 25분, 50분, 90분 타이머 프리셋
- 현재 실행 중인 프로세스 목록 조회
- 프로세스 그룹 또는 개별 프로세스 블랙리스트 등록
- 그룹 차단 중 특정 프로세스 예외 등록
- 차단 전 10초 유예 경고 표시
- 사용 기록 JSON 저장
- 날짜별 사용 기록 조회
- 오늘/월간 집중 통계 표시
- 달력 날짜별 집중 기록 하이라이트
- 차단 프로세스 표시 이름 및 메모 편집

## 프로젝트 정보

- Framework: .NET 10 WPF
- UI: WPF, MaterialDesignThemes, MahApps.Metro
- Data: JSON 파일 저장
- Language: C#

## 실행

Visual Studio에서 솔루션을 열고 실행하거나, 프로젝트 폴더에서 빌드 후 실행합니다.

```powershell
dotnet build
dotnet run --project WorkFocusManager\WorkFocusManager.csproj
```

## 저장 파일

앱 실행 폴더 기준으로 설정과 사용 기록이 저장됩니다.

- `SystemConfig.json`: 상태 문구, 이름, 블랙리스트, 예외 목록
- `TimerLogs\yyyy-MM-dd.json`: 날짜별 집중 세션 기록

## 사용 흐름

1. 설정 탭에서 상태 문구, 이름, 기본 시간을 설정합니다.
2. 현재 프로세스 탭에서 방해되는 프로세스를 블랙리스트에 추가합니다.
3. 타이머를 시작합니다.
4. 블랙리스트 프로세스가 감지되면 10초 경고 후 종료됩니다.
5. 세션이 끝나면 사용 기록과 통계가 저장됩니다.

## 참고

일부 시스템 프로세스는 권한 문제로 정보 조회 또는 종료가 실패할 수 있습니다. 이 경우 앱은 해당 프로세스를 건너뛰고 계속 동작합니다.
